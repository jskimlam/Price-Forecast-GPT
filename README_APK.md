# Petrochem Forecast Android APK

- App: Petrochem Forecast
- Package: com.jskim.petrochemforecast
- Dashboard: https://jskimlam.github.io/Price-Forecast-GPT/
- Launcher icon: Candidate 2 concept (petrochemical plant + cyan rising forecast line)
- The APK is a lightweight WebView shell. Dashboard updates are reflected without rebuilding the APK.
- Capture-card PNG save/share is bridged to Android when running inside the APK.
